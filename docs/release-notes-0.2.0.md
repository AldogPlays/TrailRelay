# TrailRelay 0.2.0

TrailRelay now opens on a map that shows saved trails. Select a route from the map or My Trails to focus its geometry and open a compact details sheet. Taps where routes overlap open a chooser.

- Preview Community routes on the map before saving them. Saved and imported GPX routes open from local storage.
- Browse Community with a compact search and filter row; full filters open in a bottom sheet.
- Use the Explore sheet to reach My Trails, Community, Downloads & Storage, Import GPX, and Settings.
- Manage route GPX files and aerial map packages separately in Downloads & Storage. View available size information and live download progress; pause, resume, or remove aerial packages without removing routes, and remove routes without removing aerial packages.
- See clearer route and aerial status in Trail Detail and across the app, with a consistent Material 3 layout.
- Use the new Keep screen awake setting while TrailRelay is in use.

Android 8.0 (API 26) or newer. No account or user API key is required. Offline aerial coverage remains limited to the downloaded area and zoom range; check saved routes and imagery without network access before heading out.
