# TrailRelay 0.3.0

This release adds Field Navigation Basics and Map Layers & Cartography.

- Choose North Up or Heading Up, with improved follow, manual pan, and recenter behavior.
- See GPS speed in mph on the map, with unavailable or stale readings handled more reliably.
- Use Open in Maps to send either trail endpoint to an installed map app.
- Switch between USGS Aerial, Hybrid, and Topo maps. Your map choice persists across launches.
- Download Aerial, Hybrid, and Topo packages independently for the same trail, with offline status matched to the selected map mode.
- New offline packages follow a trail corridor with surrounding context instead of downloading the entire route bounding box. Existing aerial packages remain recognized.
- Manage map packages by mode in Downloads & Storage, with clearer status and removal feedback while keeping route files separate.
- Enjoy smoother map-control placement around the selected-trail sheet.
- Recover missing or unreadable Community GPX files more reliably while preferring valid local files, with fixes for route cleanup and navigation edge cases.

Android 8.0 (API 26) or newer. No account or user API key is required. Offline maps cover only the downloaded area and zooms 12–16; download each map mode you need and check it without networking before heading out.
