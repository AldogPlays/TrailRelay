# TrailRelay 0.1.0 — early alpha

Release candidate notes; an APK has not been published as part of this milestone.

- USGS / The National Map aerial imagery.
- Foreground GPS location, follow, and recenter.
- GPX import and a persistent local **My Trails** library.
- Community trail catalog with local search and filtering.
- Community GPX downloads saved for offline use.
- Offline aerial imagery around trails, with download progress, pause/resume, and removal.

Android 8.0 (API 26) or newer. No account or user API key required.

This is an early alpha. Downloaded imagery covers a padded trail bounding box at zooms 12–16; coverage outside that area or zoom range may require networking. Check downloaded trails and imagery with networking disabled before heading out. Keep another navigation option available.
