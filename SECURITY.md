# Security

TrailRelay is an early-alpha project maintained by one developer.

Please do not post vulnerabilities as ordinary public issues when the details would expose an exploit. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Advisories → Report a vulnerability**.

If that option is unavailable, open an issue asking for a private reporting channel without including exploit details, credentials, or sensitive data. Share those details only after a private channel is arranged.
